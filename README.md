# 河畔斗地主

Windows 离线斗地主。玩家与两名电脑 AI 对局，无登录、无广告、无联网功能。

## 0.6.5 更新

- 手牌由 `76 × 110` 缩至 `64 × 92`，桌面小牌由 `48 × 68` 缩至 `40 × 57`，同步收紧字面、JOKER 图案和叠牌间距。
- 叫分与出牌方向改为逆时针：您 → 右侧老林 → 左侧小河；AI 座位编码和残局搜索同步调整。首次升级会保留累计积分与设置，并重新发当前一局牌。

## 0.6.4 更新

- 产品统一采用原创名称“河畔斗地主”，同步修改窗口标题、程序属性、安装包名称及桌面快捷方式。
- 存档目录保持不变，升级安装不会重置已有积分和设置。


## 当前玩法

- 标准三人斗地主，随机首叫，支持不叫、1分、2分、3分。
- 支持单张、对子、三张、三带一、三带二、顺子、连对、飞机、飞机带单、飞机带对、四带二、四带两对、炸弹和王炸。
- 顺子、连对和飞机主体只允许 `3` 到 `A`，不允许 `A2345`、`23456` 或 `JQKA2`。
- 炸弹、王炸、春天和反春天翻倍。
- 三方累计积分、本局状态和设置自动保存在本机。
- 可选记牌器，只显示未知且尚未打出的牌数，不显示电脑暗牌。
- AI 决策只接收自己的手牌与公开牌局信息。
- 固定小牌面、直线出牌动画，并提供原创离线背景音乐开关。
- 可独立开关离线语音：播报对子、三带二、飞机、炸弹等牌型；电脑剩一张或两张时会报牌，局末用不同音效区分胜负。
- 提示只负责选牌；确实无牌可压时会自动选择“不出”。
- AI 包含对手剩一张/两张、农民守门和队友尾牌配合规则。
- AI 分开处理地主、地主上家和地主下家；十张以内使用精确拆牌计算。
- 存档保留完整动作历史，便于复盘和定位异常决策。

## 0.5.0 更新

- 墨绿牌桌、暖白牌面、可辨识人物头像，简化操作栏；20 张手牌在小窗口中仍保持固定大小与位置。
- JOKER 使用原创矢量小丑图案。炸弹、王炸保留冲击波与音效。
- 背景音乐改为原创 32 小节 AABA 乐曲（约 87 秒），带柔和键盘音色、低音、鼓刷、轻微摇摆节奏与混响，音量可独立调整。
- 最后一手之后先亮牌再结算，结算页也可返回查看剩余手牌。
- 总剩余牌数 15 张以内使用受限采样与团队 minimax 残局搜索，比较同一组可能暗牌分配下各行动的结果。超出预算时保留规则策略，不把未完成的搜索当作输赢结论。
- 使用公开底牌约束可能分配。AI 接口不接收其他玩家的手牌；两名农民按共同获胜目标推演。
- 修正无谓抢队友出牌权、不能拆牌挡报单、王炸加小牌丢失出牌权等问题。AI 在后台 Worker 计算。

## 0.6.3 更新

- 将以“平均分差”为目标的 DouZero ADP 模型替换为以“胜率”为目标的 DouZero WP 模型，减少为了翻倍而过早消耗炸弹、王炸的倾向。
- 500 组连续种子的同牌双向对战（共 1000 局）中，WP 对 ADP 以 534:466 获胜；500 局行为审计未发现符合“前期无意义王炸”定义的出牌。
- 模型来源固定到公开镜像的具体版本，并以旧 ADP 检查点的完全一致 SHA-256 核验镜像来源；三个 WP 模型转换后逐批验证 PyTorch/ONNX 评分与最佳动作一致。

## 0.6.2 更新

- 修复模型过度保守：地主只剩一两张且刚出过牌时，农民只要有合法牌能压就必须抢回牌权，不允许连续放行。
- 地主上家作为最后一道关口时，会主动压住地主的小单张或小对子，不再整局机械“不出”。
- 增加批量过牌审计；同牌对战中新 AI 仍以 52:28 战胜 0.5.2 规则 AI。

## 0.6.1 更新

- 增加残局硬防守：地主剩两张时，农民领牌不再送对子；优先出地主无法一手接完的牌，没有合适组合时拆牌顶大单张。
- 地主报单或报双并处在下家时，农民会在必要时压住队友的单张或对子，避免直接交牌权。
- 这些定式会在神经网络出牌前执行，不再被模型绕过；自己能够一手走完时仍会直接获胜。

## 0.6.0 更新

- 内置 DouZero WP 三座位预训练模型，以 ONNX/WASM 在后台离线推理；无需联网、Python 或独立服务。
- 模型使用自己的手牌、未知牌集合、剩余张数和公开动作历史，不读取其他玩家真实手牌。
- “提示”也使用同一模型；模型不可用时自动回退到原有规则与残局搜索 AI。
- 40 组同牌双向对战（共 80 局）中，新 AI 对 0.5.2 规则 AI 赢 56 局；中位单步推理 0.4 毫秒，95% 在 2.3 毫秒内。

模型来源、固定版本、许可和文件校验值见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 与 `public/models/manifest.json`。

## 0.5.2 更新

- 内置 55 段离线中文语音，出牌时会播报具体牌面或牌型。
- 两名电脑玩家剩一张或两张牌时使用不同声音报牌。
- 胜利与失败使用不同的局末提示音；语音和背景音乐可分别开关。

当前 AI 由离线 DouZero WP 模型、公开信息编码、残局搜索和强制定式共同组成；不读取暗牌，但不完全信息下仍可能判断失误。模型来源和许可见上方第三方说明。

开发时可打开 `/?preview=table`、`/?preview=reveal-loss`、`/?preview=live` 检查 20 张手牌、结束亮牌及后台残局决策；这些独立预览不读写玩家存档，正式构建不包含入口。

不洗牌/整齐发牌模式已作为后续功能预留，初版暂不开放。

## 本地运行

首次安装依赖：

```powershell
npm install
```

之后可以双击 `启动本地测试.cmd`，或执行：

```powershell
npm run dev
```

## 验证与打包

```powershell
npm test
npm run build
npm run dist
```

也可以双击 `生成安装包.cmd`。完成后，安装版和便携版位于 `release` 文件夹。

开发版和正式版使用不同存档目录：

- 开发版：`%APPDATA%\RiverLabDoudizhu-dev`
- 正式版：`%APPDATA%\RiverLabDoudizhu`

更新或重新安装不会主动删除正式版存档。
